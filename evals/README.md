# Evals

这里记录「美股研究 Skill」的人工验证方法。

这些测试不是为了判断模型是否给出某个固定答案，而是观察 Skill 是否稳定改变研究行为，例如：

- 是否先验证用户前提；
- 是否使用最新且适合证明对应事实的来源；
- 是否区分收入、订单、RPO、ARR 等不同指标；
- 是否把技术变化真正连接到客户价值和商业结果；
- 是否区分已经兑现的经营事实与未来预期；
- 是否在证据不足时停止推断；
- 是否能够深入研究，同时避免把简单问题自动扩展成完整报告。

## 为什么不保存固定标准答案

财报、公司经营数据和产业数据会持续变化。

因此，这里的测试主要保存：

1. 测试问题；
2. 应观察的关键行为；
3. 统一评价标准。

对需要实时信息的案例，执行时应重新检索截至测试日最新可获得的数据，而不是复用历史答案。

## 如何进行 A/B 测试

对同一个问题分别运行两次：

**A：不加载 `equity-research` Skill**

**B：加载 `equity-research` Skill**

除 Skill 是否加载外，尽量保持模型、问题和工具环境一致。

然后按照 [`rubric.md`](./rubric.md) 中的维度进行比较。

测试案例见 [`cases.md`](./cases.md)。

## 当前验证范围

当前公开案例覆盖：

- 财报研究；
- 公司研究；
- 产业研究；
- 专业指标解释；
- 用户前提校验；
- 先行指标与收入确认；
- 已兑现价值与未来预期的区分；
- 输出长度和研究边界。

这些 Evals 主要用于检查研究行为是否稳定，不代表对任何公司或股票的投资结论。
